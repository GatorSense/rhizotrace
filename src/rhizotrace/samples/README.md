# Sample images

Three 510 x 720 pixel crops of switchgrass minirhizotron images at 300 DPI, each as the
photo (`photos/`) and its hand-made root mask (`masks/`). They come from the PRMI dataset
(Xu et al., 2022), https://doi.org/10.5061/dryad.2v6wwpzp4, released under CC0.
